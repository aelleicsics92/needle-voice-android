# Needle Voice
Assistente vocale Android.
- **Tocca l'icona**: ascolta subito, esegue, si chiude.
- **Tieni premuta l'icona > "Apri Needle"**: app completa (note, casa, AI, opzioni). Nell'overlay c'è anche il pulsante "Apri app".
- Funzioni: Home Assistant (luci/prese), timer di sistema, note, WhatsApp/SMS/chiamate con rubrica, meteo, navigazione, calendario, apertura app, multi-AI (ChatGPT, Claude, Gemini) con foto.
- Build: GitHub Actions > "Build Needle Voice APK" > Artifacts.
